# 批量会话确认：兼容性修复与弹窗整理

**Goal:** 修复旧 MCP 定义拒绝 archive 导致中断会话无法归档，并让选择与逐项错误清楚可见。

**Evidence:** 2026-11-18 17:18:11/13 本机桌面日志明确记录 ai_todos_confirm_session 拒绝 archive（-32602）。真实会话数据库副本验证普通确认拒绝 interrupted，显式 archive 可成功，未改动真实记录。

**Design:** 归档放入现有 ai_todos_wiki 的稳定 action 信封，由本地服务严格校验同一份显示版本；普通确认仍使用旧工具。专用紧凑弹窗包含选择概览、横向状态选择、项目短名/状态标签列表和固定底部操作；逐项保留失败原因。刷新只更新显示，不能自动提交新版本。确认成功与刷新失败分开处理，避免操作已成功却被报为失败。
