# 原生 Codex 经验沉淀执行器

2026-11-16：已实现经验提取和 Wiki 对照执行器替换。完整 ingest 的 raw/hot/provenance/manifest/lint 扩展仍见 `wiki-ingest-integration-design.md`，本次不将其标记为已完成。

## 运行方式

- 用户先选择模型及强度，再手动启动；缺省且没有已保存选择时拒绝执行，不跟随变化的全局默认配置。
- 通过官方分页接口核对指定来源 ID，连续两次完整读取相同才固化来源。
- 原文保存在本机数据目录 `wiki-agent/tasks/<job>/<snapshot>/source.json`，同时保存 `manifest.json`。目录权限 0700、文件 0600；不先写正式 Wiki 或 raw。
- 一个持久 Codex 线程自主调用 `wiki_source_index` 和 `wiki_read_source`。每页约 24 KB，保留 turn/item、字段路径和字符位置。分页仅用于工具传输；不再每页新建模型会话或自行合并压缩结果。
- Codex 原生管理工具循环与上下文。需要时可重读来源；原生压缩不保证无损。
- 只有明确 `turn/completed=completed`、结构有效、原文全部页已读且每条至少有一个完整真实引用时，才保存待审核候选。覆盖不代表结论正确。
- 后台线程通过持久 ID 登记和私有 cwd 两种方式从 ai-todos 普通会话列表、看板和可提取来源中过滤。Codex 自身侧边栏可能保留该原生持久线程，这不等于 ai-todos 待办。

## 权限与审核

专用执行器不改变任务定义生成器的无工具策略。shell、外部 MCP、apps/plugins/hooks、网络和子 Agent 等关闭。正式资料由主机提供只读工具，工具参数只接受页号或索引偏移，不接受路径、命令或写操作。未知工具及批准请求会中止任务。

本机 Codex 0.167.0 的动态工具需要 code-mode host，专用执行器保留这项能力；禁用它会让动态工具返回 `code-mode host is disabled`。真实探针验证过工具成功往返。

用户逐项确认/排除及保存意见后才运行 Wiki 对照。对照继续复用已有页面选择、双份笔记、索引与追加日志的提案校验器；同一审核版本的并发请求复用一次执行，可取消，关停时也会中断。失败后重新读取当前页面并新建线程，不混用上一次 Wiki 上下文。

最终批准仍由原有受保护 writer 消费绑定版本和全部差异的票据执行；Agent 不写正式资料，批准后不再生成新内容。

## 恢复与诊断

- `wiki_analysis_jobs` 保存 engine、来源摘要、线程/轮次 ID、最近活动、工具数、压缩数、尝试次数和错误；候选保存对应 jobId 和完成时线程快照。
- 同模型、同原文快照、同执行器版本才恢复提取线程。换模型或来源变化使用新线程；旧的 chunk/merge 断点不混用。
- 重试重新读取全部来源页，原生历史用于继续推理，不把旧工具调用次数冒充本轮覆盖。
- 每次 RPC 最多等待 45 秒；原生整理最多 30 分钟，连续 10 分钟无本线程活动才判定无活动超时。持续活动不会被原来的 120 秒整轮硬限时截断。
- 取消调用 `turn/interrupt` 并收尾子进程。服务关停覆盖提取和对照；服务重启后需要用户显式重试，不自动消耗模型额度。
- 不持久化模型推理正文或输出子进程 stderr；通过结构化状态和轮次错误定位阶段。上游若无细节，不猜测网络或排队根因。

## 已验证

- 隔离协议测试覆盖完整来源/篡改、引用前缀误匹配、后台过滤和重启后的身份、模型一致性、原生工具循环、压缩通知、取消/超时、持久恢复、并发对照与取消。
- 真实 Codex `gpt-6.1-sol / low` 探针：工具读取成功，手动原生压缩完成后可恢复同一线程，并重读来源确认原标记。
- 真实 STE 会话：15 页，中途取消后恢复同一线程并完成，得到两项与技能用途和会话激活范围有关的具体经验。
- 此前合并超时的支付问题会话：16 页，原生线程完成，保留支付提示的三种触发条件及未验证边界，同时识别本地 ingest 规范的纠正。
- 两场真实提取均仅保存到隔离数据库；对正式 Wiki 全部文件做前后 SHA-256 核对，未变化。结果仍是待人审候选，不证明质量普遍达标。
- 浏览器隔离流程完成手动选择、提取、Markdown/折叠、逐项确认和排除、意见保存、Wiki 对照、双份笔记和索引/日志 diff、测试 Wiki 批准写入。会话与模型为协议替身，业务后端和写入器为真实代码。

## 已知边界

初版来源读取仍有 64 MB 上限，单条协议响应不能超过原有传输边界；超限明确失败。图像等非文本内容只保留来源字段，不保证语义识别。Wiki 查重仍由选中页面决定，既有对照器的最多八页限制未在本次重构中扩大。
