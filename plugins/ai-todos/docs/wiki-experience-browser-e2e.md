## 本次复现并修复的问题

1. **旧 MCP 操作列表拒绝新操作**：使用旧版实际 MCP 包和新版服务，在浏览器中复现截图的 invalid discriminator 报错。新版改用稳定的 MCP 信封，由服务端严格校验具体操作；旧连接先执行兼容的 list，显示本地工作台入口。旧版宿主测试中入口成功打开页面。服务端仍拒绝 MCP 批准。
2. **任务完成后没有自动展示候选**：先切换任务状态导致轮询 effect 清理，截断结果选择。改为先加载并选择候选再切换状态；用首次 120 分段流程验证。
3. **YAML 元数据干扰 Markdown 预览**：正文预览移除开头 frontmatter；完整原文仍保留在编辑框和差异中。浏览器验证表格渲染且无 YAML 标题。
